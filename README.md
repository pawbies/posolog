# posolog

posolog is your private medication logging tool, that also provides you tools to analyze the pharmacokinetics behind your doses.

## Privacy first

posolog is built to be privacy focused by design:

- **All data stays on your device.** Medications, doses, and logs are stored locally — nothing is uploaded to a server.
- **No accounts, no sign-in.** There's no login, so there's no identity to tie your data to.
- **No analytics or tracking.** posolog doesn't collect usage data, telemetry, or send anything to third parties.
- **You control your data.** Export or import your data whenever you want — it never leaves your device unless you choose to share it.

## Features

- Log medications and doses over time
- Timeline and tracking views of your dosing history
- Pharmacokinetics calculator to analyze doses
- Statistics on your medication history
- Local export/import of your data
- Built-in wiki for reference information

## Tech stack

Built with [Expo](https://docs.expo.dev/versions/v57.0.0/), React Native, Expo Router, and NativeWind.

## Development

1. Install dependencies

   ```bash
   bun install
   ```

2. Start the app

   ```bash
   bun x expo start
   ```
